# Nancy Karoki — Portfolio

Static personal portfolio: HTML, CSS, and JavaScript. No build step required.

## Preview locally

From this directory:

```bash
# Python
python3 -m http.server 8080

# or Node
npx serve .
```

Open [http://localhost:8080](http://localhost:8080).

## Deploy

Push to the connected GitHub repo and deploy with Vercel (or any static host) pointing at the project root. Entry file: `index.html`.

## Structure

- `index.html` — page content
- `css/styles.css` — theme and layout
- `js/main.js` — theme toggle, nav, scroll reveal, contact mailto
